# 🎙️ Voice Notes to Action Items

An AI-powered application that converts voice notes into text and automatically generates a summary, action items, and deadlines.

## Features

- 🎙️ Upload audio files
- 📝 Speech-to-text using Whisper
- 🤖 AI analysis using Ollama and Llama 3.2
- 📌 Automatic summary generation
- ✅ Action item extraction
- 📅 Deadline identification
- 🌐 Simple Streamlit web interface

## Technologies Used

- Python
- Streamlit
- OpenAI Whisper
- Ollama
- Llama 3.2
- FFmpeg

## How It Works

Audio File
↓
Whisper Speech Recognition
↓
Transcript
↓
Llama 3.2 through Ollama
↓
Summary + Action Items + Deadlines
